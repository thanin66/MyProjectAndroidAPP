# Mobile Application PCshop Project

เว็บแอปพลิเคชันหรือระบบแอปพลิเคชันบนระบบปฏิบัติการ Android สำหรับสั่งซื้อและประกอบคอมพิวเตอร์ (PCshop) พัฒนาขึ้นโดยใช้โปรแกรม Android Studio ด้วยภาษา Java เพื่อจัดการโครงสร้างการเลือกสเปกคอมพิวเตอร์และแสดงผลรายการคำสั่งซื้ออย่างเป็นระบบ

## หัวข้อและฟังก์ชันหลักที่นำมาใช้ (Core Features)
* Intent: ใช้สำหรับจัดการการเคลื่อนย้ายและเชื่อมโยงการทำงานระหว่างหน้ากิจกรรม (Activity) ต่างๆ ภายในแอปพลิเคชัน
* RecyclerView: ใช้สำหรับการจัดรายการแสดงผลคำสั่งซื้อคอมพิวเตอร์ที่ถูกเพิ่มเข้ามา เพื่อให้สามารถรองรับการแสดงข้อมูลปริมาณมากได้อย่างมีประสิทธิภาพและลื่นไหล
* Layout & UI: การออกแบบส่วนต่อประสานกับผู้ใช้เพื่อรองรับการกรอกข้อมูลและการเลือกตัวเลือกสเปกสินค้า
* Glide: ไลบรารีสำหรับดึงรูปภาพประกอบชิ้นส่วนคอมพิวเตอร์จากอินเทอร์เน็ตเข้ามาแสดงผลบนหน้าแอปพลิเคชัน

---

## โครงสร้างและการทำงานของซอร์สโค้ด (Source Code Structure)

### 1. ส่วนการจัดการข้อมูลและหน้าหลัก
* Class Order: คลาสที่ทำหน้าที่เป็นแบบจำลองข้อมูล (Model) ประกอบด้วยคุณลักษณะ (Attribute) ต่างๆ ของสินค้า พร้อมฟังก์ชัน Getter และ Setter สำหรับสร้างออบเจกต์เพื่อส่งต่อข้อมูลไปยังคลาสอื่น
* MainActivity: หน้าแรกของแอปพลิเคชัน ประกอบด้วยข้อความ รูปภาพ และปุ่มกด (Button) เพื่อเปิดไปยังหน้าฟังก์ชันหลักของระบบ [00:01:05]

### 2. ส่วนการจัดการคำสั่งซื้อ (Order Activity)
* OrderActivity: หน้ากิจกรรมหลักที่ใช้สำหรับกรอกและรับข้อมูลการสั่งซื้อคอมพิวเตอร์ [00:01:11]
* ส่วนรับข้อมูลประกอบด้วยช่องใส่ชื่อผู้ใช้งาน (Username) และส่วนเลือกตัวเลือกสเปกคอมพิวเตอร์ผ่าน Option Choice (Spinner/Select) ได้แก่ ชิปประมวลผล (Processor), การ์ดจอ (Graphic Card), หน่วยความจำ (RAM) และพื้นที่จัดเก็บข้อมูล (Storage) [00:03:51]
* ปุ่ม Add Order (เดิมคือปุ่ม Check): ทำหน้าที่ตรวจสอบข้อมูล หากช่องกรอกข้อมูลว่างระบบจะแจ้งเตือนว่าต้องใส่ข้อมูลให้ครบถ้วน หากข้อมูลครบถ้วนระบบจะนำข้อมูลสเปกไปสร้างเป็นออบเจกต์แล้วบันทึกเพิ่มเข้าไปในรายการคำสั่งซื้อ (Order List) [00:02:10]
* การจัดการเงื่อนไขภายในเลือกใช้ Switch-Case แทนโครงสร้าง If-Else เพื่อความเหมาะสมในการทำงานบางส่วน [00:02:25]

### 3. ส่วนการแสดงผลรายการ (Order List & Adapter)
* OrderAdapter: ตัวเชื่อมโยงข้อมูลที่มี View Holder ทำหน้าที่กำหนดและจัดสัดส่วนการแสดงผลข้อมูลแต่ละรายการ โดยแปลงข้อมูลข้อความ (TextView) และดึงรูปภาพจากอินเทอร์เน็ตผ่าน Glide มาแสดงบน Image View [00:03:07]
* OrderListActivity: หน้าจอแสดงผลรายการคำสั่งซื้อทั้งหมดที่ผู้ใช้งานกดเพิ่มเข้ามา โดยทำงานร่วมกับ RecyclerView เพื่อรองรับการเพิ่มและแสดงผลรายการคำสั่งซื้อจำนวนมากกว่า 1 รายการได้อย่างเป็นลำดับ [00:03:27]
* Item Order Layout: ส่วนการจัดวางตำแหน่งเลย์เอาต์ย่อยสำหรับนำไปใช้วาดแสดงผลแต่ละรายการคำสั่งซื้อภายใน RecyclerView [00:04:22]

## ขั้นตอนการทำงานของแอปพลิเคชัน (Application Workflow)
1. เมื่อเปิดแอปพลิเคชันจะพบหน้าต้อนรับ (MainActivity) ให้ผู้ใช้กดปุ่มเพื่อเข้าสู่หน้าถัดไป [00:04:41]
2. ผู้ใช้ใส่ชื่อ และเลือกสเปกคอมพิวเตอร์ที่ต้องการผ่านตัวเลือกที่มีให้ [00:04:51]
3. กดปุ่มเพื่อบันทึกคำสั่งซื้อ (Add Order) เข้าสู่ระบบ [00:05:03]
4. กดปุ่มเดินทางไปยังหน้าถัดไป (Go to Order List) ระบบจะแสดงรายการคำสั่งซื้อทั้งหมดที่เคยบันทึกไว้ในรูปแบบรายการเรียงต่อกันตามลำดับ [00:05:11]
